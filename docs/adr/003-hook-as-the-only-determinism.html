ADR 003 — Hooks are the only determinism layer

Status: accepted · foundational

Context

Having dropped the FSM and daemon (ADR 001/002), OOD still needs some rules that cannot be skipped — above all: do not complete a task without a passing inspection. If that rule lives only in a skill or agent prompt, it is model-driven and therefore soft: a model can forget it, rush it, or argue its way around it.

Decision

The only hard guarantees in OOD come from hooks, which the harness (not the model) executes on events. Everything else is soft.

The completion gate (hooks/gate-task-completed.py) reads the finishing task, and if it is marked [gate:inspect] it requires a docs/reports/NNN-inspection.html containing Verdict: GO. No GO → exit 2 blocks completion and feeds the reason back.

Consequences

easierharder / accepted
An un-bypassable gate without any FSM. Determinism by file existence. The gate keys on filename/heading conventions; needs python3; sits on the experimental Agent Teams hook surface.

Alternatives considered

  • Prompt-only enforcement — rejected: drifts; the stronger the model, the more convincingly it can justify skipping.
  • Re-introduce an FSM — rejected: the ceremony OOD set out to remove (ADR 001).
